# Calculadora Canopolis

Ejecutable portátil de Windows (ventana propia, sin navegador).

## Funciones
- MRC (recuperar memoria), M- (restar a memoria), M+ (sumar a memoria)
- CE (borra solo la entrada actual) / ON-C (borra toda la operación)
- %, √ (raíz cuadrada), +/-
- Orden de operaciones (PEMDAS) y paréntesis
- Punto decimal y separador de miles con comas

## Teclado físico (probado por lógica antes de entregar)
- Números y `+ - * /`, `( )`, `.`, `%`
- **Enter** = `=`
- **C** o **Esc** o **Delete** = borra todo
- **Backspace** = retrocede un carácter

## Obtener el exe
Pestaña **Actions** → **Compilar Calculadora** → **Run workflow**.
En ~4 min, el exe aparece en **Releases** (portada del repo): `CalculadoraCanopolis.exe`.
Es portátil: cópialo donde quieras, doble clic y abre. No requiere instalación.
